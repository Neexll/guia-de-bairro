# 📍 Guia de Bairro

Plataforma moderna e responsiva para conectar moradores aos melhores negócios, serviços e estabelecimentos locais.

## ✨ Funcionalidades

- 🔍 **Busca Dinâmica & Filtros**: Pesquise estabelecimentos por nome, categoria ou bairro com barra de busca fixa.
- 🏪 **Catálogo de Negócios**: Listagem interativa de restaurantes, lojas, serviços e conveniências com avaliações, horários e rotas.
- 🌓 **Tema Claro e Escuro**: Suporte a alternância rápida de tema (Light / Dark mode).
- 📢 **Área de Anúncio**: Formulário e fluxo para comerciantes cadastrarem e divulgarem seus negócios.
- 📱 **Totalmente Responsivo**: Layout otimizado para celulares, tablets e computadores.

## 🛠️ Tecnologias

- **HTML5** semântico
- **CSS3** moderno (CSS Variables, Flexbox, Grid, Animações)
- **JavaScript (ES6+)** nativo para interatividade

## 🚀 Como Executar

Por ser um projeto web estático, não requer instalação de dependências:

1. Clone o repositório ou baixe os arquivos:
   ```bash
   git clone https://github.com/Neexll/guia-de-bairro.git
   ```
2. Abra o arquivo `index.html` em qualquer navegador moderno (ou use extensões como Live Server no VS Code).
